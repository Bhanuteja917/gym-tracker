# Gym Tracker

The app lives in `web/`: a Next.js PWA (Neon + Prisma + Better Auth, offline-first
with Dexie). Read `web/AGENTS.md` before changing it; run commands from `web/`.

- Plan and decisions: `docs/PWA-PLAN.md`; offline storage and sync: `docs/OFFLINE-PLAN.md`.
- Run `npm run check` in `web/` (typecheck, lint, tests) before committing.
